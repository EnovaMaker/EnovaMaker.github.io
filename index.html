Open source

NixOS modules for digital sovereignty: censorship-resistant networking, self-hosting, supply-chain provenance, and payments. All MIT-licensed. Two ship working code today; the rest are published designs with their architecture and roadmap in the open.

  • nixos-webtunnel-bridge working
    A Tor WebTunnel bridge relay from one declaration — Tor, the transport, nginx with TLS and a cover site. Two-node VM test in CI.
  • nixos-tor-anti-dos working
    Per-source rate limiting for a Tor relay's ORPort. Picks up what the unlicensed, unmaintained tor-ddos left behind.
  • nixos-sovereign-host design
    Community self-hosting: Matrix with bridges, Syncthing, monitoring, backup and SSO.
  • nixos-sovereign-host-censorship design
    Onion services, an obfs4 bridge, metadata hardening and a one-flag lockdown mode.
  • nixos-provenance-guard design
    Checks that a new flake-input revision is a legitimate continuation of its history, not a repository takeover.
  • nixos-local-first design
    Self-hosting the NextGraph end-to-end-encrypted local-first stack.
  • nixos-taler design
    Production operations for GNU Taler: auditor role, typed AML/KYC options, TLS, encrypted backups and systemd sandboxing.
  • nixos-iot-edge design
    Declarative IoT ingestion: an MQTT broker, a time-series store and a query API.
